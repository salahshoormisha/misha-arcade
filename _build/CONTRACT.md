Every agent working on this build MUST read this file and obey it exactly.
It is the interface between ~20 independently-built games and one shared core.

## 0. Hard constraints (non-negotiable)

- **Static only.** GitHub Pages. No server, no build step, no npm, no bundler, no TypeScript,
  no framework, no `import` of external modules at runtime. Plain HTML + CSS + ES2019 JS.
- **No external runtime dependency for gameplay logic or data.** Everything needed to play
  must be a file in this repo. (Exception: photo games may load images from
  `upload.wikimedia.org` / `themealdb.com` — images only, and every such game must degrade
  gracefully to a text-only fallback when offline.)
- **Runs on an 8 GB MacBook Air and on iPhone Safari.** Keep every data file under the size
  budget given below. No file over 300 KB. No blocking work over 50 ms on the main thread.
- **localStorage is the only persistence.** It can be wiped; never treat it as safe.
- **Zero build-time codegen at page load.** Data files are pre-generated by Python scripts in
  `_build/` and committed. Scripts must be re-runnable and deterministic.
- Repo root: `/Users/mishasalahshoor/cbai-ops/misha-arcade`
- Never use `Math.random()` for anything that must match between two players. Use the seeded
  RNG from the core (§2).
- **No emoji-as-flag** for gameplay art (renders differently per platform). Use the shipped SVGs.

## 2. Core engine API — `core/arcade.js` (global `A`)

Assume this exists and is loaded before your game. Do not reimplement any of it.

```js
// ── identity & dates ────────────────────────────────────────────────────────
A.today()                  // "2026-07-25" in LOCAL time
A.dayNumber(dateStr?)      // integer days since 2026-07-26 epoch (>=0), local
A.dateFromDay(n)           // "YYYY-MM-DD"

// ── deterministic randomness (two players, same day, same puzzle) ──────────
A.rng(seedString)          // → function(): float in [0,1)   (mulberry32 over FNV-1a hash)
A.rngFor(gameId, dayN)     // → convenience: A.rng(gameId + ":" + dayN)
A.pick(rand, array)        // one element
A.shuffle(rand, array)     // NEW shuffled array (Fisher-Yates, does not mutate)
A.dailyIndex(gameId, dayN, poolSize)
     // Deterministic non-repeating walk over 0..poolSize-1: a seeded permutation of the
     // pool re-shuffled each cycle, so no repeat until the pool is exhausted.

// ── per-game state & stats ─────────────────────────────────────────────────
A.load(gameId, dayN)       // → saved in-progress/finished state for that day, or null
A.save(gameId, dayN, obj)  // persist in-progress state (autosave; survives reload)
A.finish(gameId, dayN, {
   score,                  // raw game score (any scale)
   norm,                   // 0..100 normalised — see §3. REQUIRED.
   won,                    // bool
   detail,                 // short string for the league table, e.g. "4/6" or "3,120 pts"
   shareGrid,              // array of emoji-row strings for the share card
   stamps,                 // OPTIONAL array of ISO2 codes correctly identified → passport
   durationMs,             // OPTIONAL
})                         // idempotent per (gameId, dayN); writes stats, streak, passport
A.stats(gameId)            // → {played, wins, streak, best, curve:{...}, lastDay, avgNorm}

// ── sharing & head-to-head ─────────────────────────────────────────────────
A.share(text)              // navigator.share → clipboard fallback → toast
A.shareCard(gameId, dayN)  // → canonical share string for that game/day
A.duelLink(dayN)           // → absolute URL to league/ with today's card packed in the hash
A.readDuel()               // → parsed opponent card from location.hash, or null
A.card(dayN)               // → { day, results:{gameId:{norm,detail,won}}, total, name }

// ── passport (cross-game country collection) ───────────────────────────────
A.stamp(iso2, gameId)      // record a correctly identified country
A.passport()               // → { "IR": {first:"2026-07-26", games:["flagle",...]}, ... }

// ── misc ───────────────────────────────────────────────────────────────────
A.player()                 // → "misha" | "david" (whose device this is; set in settings)
A.settings()               // → { player, hardMode, colourblind, sound, reduceMotion, glam }
A.on(evt, fn)              // "finish" | "settings"
A.backup()                 // → JSON string of everything
A.restore(jsonString)      // → bool
A.registry                 // → array of every game's metadata (see §5)
```

## 3. Normalised score (`norm`) — the cross-game currency

Every game MUST report `norm`, an integer 0–100, so the Daily Run and the league can compare
a Wordle to a TimeGuessr. Rules:

- **100** = a perfect/exceptional result that a strong player hits <10% of the time.
- **~70** = a solid, typical win.
- **0** = did not solve / bottom-of-the-barrel.
- Never award 100 for merely finishing.
- Guess-based games (Wordle/Flagle/Tradle/Globle): map guesses used → `norm` on a curve where
  the modal winning guess count lands ~70, a 2-guess win lands ~100, and a loss lands 0–15.
- Points-based games (TimeGuessr/GeoGuessr): `norm = round(100 * points / maxPoints)` but
  apply the game's own realistic ceiling, not the theoretical one, if a perfect score is
  effectively unreachable.
- Time-based games (crosswords): `norm = clamp(round(100 * par / seconds), 0, 100)` where
  `par` is the target time; solving in exactly par = 100. Give partial credit for a
  reveal-assisted finish (cap at 60).
- Grid games (Geogrid/Connections): combine correctness and rarity/mistakes.
- Document your formula in a comment at the top of your `game.js`.

## 6. Data file contracts

All data files are plain JS assigning one global. No trailing logic. Values are **factual** —
if you are not sure a fact is right, leave the entry out. Every file starts with a comment
naming its source and generation script.

### `countries.js` → `window.AD_COUNTRIES` (array, ~250)
```js
{ i:"IR", n:"Iran", n3:"IRN", num:364, cap:"Tehran", capll:[35.7,51.42],
  ll:[32,53], reg:"Asia", sub:"Southern Asia", pop:83992949, area:1648195,
  locked:0, bord:["AF","AM","AZ","IQ","PK","TR","TM"], lang:["Persian"],
  cur:["Iranian rial"], un:1, ind:1, alt:["Persia"], demo:"Iranian",
  island:0, hemi:"N", tld:".ir" }
```
Budget ≤ 90 KB. Include a `AD_COUNTRIES_BY` index built at load: `{iso2:obj}`.
`island` and `hemi` are DERIVED (island = no land borders and not landlocked; hemi from lat).

### `world.js` → `window.AD_WORLD`
Country outlines for map rendering, silhouette quizzes and click-to-guess.
Source: Natural Earth via `_build/countries-110m.json` (public domain).
Encoding is yours to choose BUT it must expose:
```js
AD_WORLD.rings("IR")   // → [ [[lon,lat],[lon,lat],...], ...]  (outer rings, degrees)
AD_WORLD.all()         // → ["AF","AL",...] every code with geometry
AD_WORLD.centroid("IR")// → [lon,lat] area-weighted
AD_WORLD.bbox("IR")    // → [minLon,minLat,maxLon,maxLat]
AD_WORLD.land()        // → rings for all land (for a fast world backdrop)
```
Budget ≤ 300 KB total. Simplify aggressively (Douglas-Peucker); a country must still be
recognisable at 320 px wide. Key ISO2, not numeric. Verify every `AD_COUNTRIES` entry with
area > 5000 km² has geometry, and report any that do not.

### `flags.js` → `window.AD_FLAGS`
```js
{ "IR": { file:"IR.svg", ar:1.75, hard:0, colours:["green","white","red"],
          features:["tricolour","emblem"] }, ... }
```
Plus `core/data/flags/XX.svg` — minified, viewBox-normalised, ≤ 8 KB each where possible.
`hard:1` marks flags whose fine detail is lost when scaled small (busy seals/emblems).
`features` powers hint text and the flag-quiz filters.

### `words.js` → `window.AD_WORDS`
```js
{ answers5:[...], valid5:[...], answers4:[...], valid4:[...],
  boxed:[...],        // words usable by Letter Boxed (len>=3, no proper nouns)
  cross:{3:[...],4:[...],5:[...],6:[...],7:[...]},  // crossword fill wordlist
  persian:[...]       // 5-letter English words of Persian/Farsi origin, for a signature pack
}
```
Rules: `answers5` = COMMON words only (a player should recognise every one) and every entry
MUST also exist in `valid5`. No plurals ending in S as answers where avoidable, no proper
nouns, no slurs/profanity (screen against a blocklist). Every word must be validated against
`/usr/share/dict/words` OR an explicit curated allowlist with a comment. Budget ≤ 260 KB.

### `crosswords.js` → `window.AD_CROSSWORDS`
```js
{ mini:[ { id:"m001", size:5, grid:["ABCDE","F#GHI",...],  // "#" = block
           across:[{n:1,r:0,c:0,len:5,ans:"ABCDE",clue:"..."}],
           down:[...], par:90, theme:null } ],
  midi:[ { ...size:7, par:240 } ] }
```
Every grid MUST be verified: fully connected, every white square in one across AND one down
entry, minimum word length 3, no duplicate entries in a puzzle, every answer in the dictionary,
symmetric block pattern (180° rotational) for midis. Clues: NYT-Mini voice — short, plain,
occasionally playful; never reuse a clue's answer word in the clue.

### `connections.js` → `window.AD_CONNECTIONS`
```js
{ packs:[ { id:"general", name:"MIXED BAG", boards:[
    { id:1, diff:2, groups:[ {name:"THINGS THAT...", colour:"y", tiles:["A","B","C","D"], note:"..."} x4 ],
      epilogue:"..." } ] } ] }
```
Colours `y|g|b|p` in ascending difficulty. **Every board must have a UNIQUE solution** —
deliberate double-fit traps are good, but must be resolvable by elimination. Author packs:
`general`, plus signature packs (see §7).

### `trade.js` → `window.AD_TRADE`
```js
{ year:2022, source:"...", countries:[
  { i:"IR", total:73.4e9,        // total exports USD
    items:[ {name:"Crude Petroleum", hs:"27", share:0.271, colour:"27"} ...] } ] }
```
`share` sums to ≤1 with an "Other" remainder. ≥8 items per country where data allows.
Colour key = HS2 section, matching OEC's palette family. ≥100 countries.

### `food.js` → `window.AD_FOOD`
```js
{ countries:[ { i:"MA", dishes:[ {name:"Lamb Tagine", desc:"...", img:"https://...", why:"..."} x3+ ] } ] }
```
≥60 countries × ≥3 dishes. `desc` = one sentence a player could guess from. `img` optional,
must be a verified-200 URL. Dishes must be genuinely characteristic, not merely available.

### `lingua.js` → `window.AD_LINGUA`
```js
{ samples:[ { lang:"Persian", script:"Arabic (Perso-Arabic)", family:"Indo-European > Iranian",
              text:"...", gloss:"...", countries:["IR","AF","TJ"], hints:["...","..."] } ] }
```
≥50 languages, script-diverse. `text` must be REAL text in that language (source it; do not
invent). This is the replacement for Ethnoguessr — culture/language, never faces.

### `photos.js` → `window.AD_PHOTOS`
```js
{ time:[ { id, url, w, h, year:1969, lat, lon, place:"Woodstock, New York, USA",
           iso2:"US", caption:"...", credit:"...", licence:"CC BY-SA 3.0",
           page:"https://commons.wikimedia.org/wiki/File:..." } ],
  place:[ { id, url, w, h, lat, lon, iso2:"JP", place:"...", credit, licence, page } ] }
```
≥100 `time` entries spread 1850–2015 (at least 8 per decade after 1900), ≥100 `place` entries
across ≥60 countries and every inhabited continent. **Every single URL must be verified HTTP
200 by the generation script**, `w`/`h` recorded, licence and credit present (legal
requirement — the game renders the credit). Use `upload.wikimedia.org` thumbnail URLs at
width 1000. Year must be the year the photo was TAKEN, sourced from Commons metadata or the
file's category, not guessed. Discard anything uncertain.

### `geogrid.js` → `window.AD_GEOGRID`
```js
{ criteria:[ { id:"landlocked", label:"Landlocked", test:"c.locked===1",
               kind:"bool", rarity:0.18 } ],
  // `test` is a JS expression string over `c` (a countries.js record), eval'd ONCE at load
  incompatible:[["landlocked","island"]],
  raritySource:"computed from countries.js" }
```
≥28 criteria across geography/demography/politics/language/economy. Every criterion must be
computable purely from `countries.js` (+ `trade.js` if needed). Provide a self-test that
prints, for every criterion pair, how many countries satisfy both — used to reject impossible
grids.
